## Assembly and Installation Guidelines

For the NS-D4 organizer:
1. Place the frame on a flat surface.
2. Identify the top and bottom sections.
3. Assemble the supporting frame using the supplied connectors.
4. Insert each drawer into its designated position.
5. Check that all drawers slide correctly.

For the NS-W2 wall-mounted rail:
1. Review the supplied installation instructions.
2. Identify a suitable mounting location.
3. Check the wall type and suitability of the supplied fixings.
4. Use appropriate installation methods for the wall material.
5. Confirm the rail is securely mounted before use.

Customers should seek qualified installation assistance if they are unsure about wall suitability or mounting safety.

## Product Issues and Replacement Procedures

Use the following guidelines when handling home-storage complaints.

- Missing components: Confirm the model and identify the missing part.
- Cracked drawers or panels: Request photographs and the affected part reference.
- Assembly difficulty: Ask which step is causing the issue before providing guidance.
- Incorrect model delivered: Request the order number and packaging photographs.
- Unstable or incorrectly mounted furniture: Advise the customer to stop using it until inspected.

For one or two damaged components, a replacement part may be appropriate.

For extensive damage or structural defects, escalate the case for a full product assessment.

Never advise customers to continue using unstable furniture.
